# Primero Currency Converter

Modern multilingual currency converter plugin for WordPress with live exchange rates, AJAX conversion, charts, dark mode, and support for more than 160 currencies.

## Features

- AJAX currency conversion without page reload
- More than 160 supported currencies
- English, Russian, and Spanish interface
- Translated currency names
- Exchange-rate history chart
- 7, 30, and 90-day periods
- Dark mode
- Searchable currency selectors
- Swap currencies button
- Recent conversion history
- Copy conversion result
- Popular exchange rates
- Automatic conversion
- WordPress Transient API caching
- Multiple exchange-rate providers
- Automatic fallback API
- Nonce protection and input validation

## Installation

1. Download the plugin ZIP file.
2. Open WordPress admin.
3. Go to `Plugins → Add New → Upload Plugin`.
4. Upload the ZIP file.
5. Install and activate the plugin.
6. Add the shortcode to any page:

```text
[primero_currency_converter]
